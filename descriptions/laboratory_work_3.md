# Лабораторная работа 3: Перенос знаний с использованием PyTorch

## Цель работы

**Цель работы** - изучить и реализовать метод переноса знаний (transfer learning) для глубоких нейронных сетей на примере задачи классификации отходов на наборе данных [Garbage Classification](https://www.kaggle.com/datasets/asdasdasasdas/garbage-classification). Перенос знаний предлагается применить к известным моделям глубокого обучения, обученным на наборе данных ImageNet.

---

## Задачи работы

Выполнение лабораторной работы предполагает решение следующих задач:

1. Загрузить набор данных Garbage Classification и выполнить предобработку данных, если это необходимо.
2. Выбрать 4 архитектуры нейронных сетей, для которых в открытом доступе существуют веса, предварительно обученные на наборе данных ImageNet.
3. Модифицировать выбранные архитектуры нейронных сетей для работы с набором данных Garbage Classification. Выбрать гиперпараметры обучения и функцию ошибки.
4. Обучить все четыре модели со случайными весами на наборе данных Garbage Classification.
5. Обучить те же четыре модели с весами, предварительно обученными на наборе данных ImageNet, на том же наборе данных Garbage Classification.
6. Сравнить результаты обученных моделей по Macro F1-score.

---

## Требования к результатам выполнения работы

1. **Структура и содержимое Jupyter Notebook**:

    - Вывести размерности данных: количество примеров в каждой выборке, форму одного изображения и меток.
    - Необходимо обеспечить демонстрацию избранных изображений и меток классов для подтверждения корректности загрузки.
    - Загрузить и обучить 4 нейронные сети (можно использовать `torchvision`). Для каждой модели провести 2 эксперимента: первый - обучить модель со случайными весами, второй - реализовать перенос знаний, используя веса, обученные на ImageNet. Всего 8 экспериментов.
    - Построить график Macro F1-score от количества эпох для всех моделей на валидационных данных. Построить сравнительную столбчатую диаграмму: модель и тип эксперимента (с кратким указанием параметров) по горизонтали, Macro F1-score на тестовых данных по вертикали.

2. **Данные и метрика**:

    - Датасет необходимо самостоятельно разделить на тренировочную, валидационную и тестовую выборки в соотношении 70/15/15.
    - Для оценки качества следует использовать **Macro F1-score**, поскольку датасет не сбалансирован.

3. **Архитектуры**:

    - Можно использовать любые сверточные архитектуры или архитектуры на базе механизма внимания (transformer, ViT и т.д.).
    - Хорошее понимание работы выбранных архитектур напрямую влияет на количество баллов за знания. Будьте готовы кратко рассказать об особенностях выбранных или одной из выбранных архитектур при очной сдаче лабораторной работы.
    - Не бойтесь выбирать сложные архитектуры - чем сложнее архитектура, тем больше в ней интересного.

## Оценивание

- Количество баллов за лабораторную работу рассчитывается по формуле:  
  $$\text{баллы} = 10 \times \text{знания} \times \text{точность}$$, 

  $$\text{знания} \in [0, 1]$$ - оценка уровня понимания материала, 
  $$\text{точность} \in [0, 1]$$ - оценка точности решения задачи. Например, точность классификации 90% - это 0.9.
