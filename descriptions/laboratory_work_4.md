# Лабораторная работа 4: Семантическая сегментация с использованием PyTorch

## Цель работы

**Цель работы** - разработать и обучить сверточную нейронную сеть для задачи мультиклассовой семантической сегментации изображений на наборе данных [SUIM](https://www.kaggle.com/datasets/ashish2001/semantic-segmentation-of-underwater-imagery-suim) с использованием PyTorch.

## Задачи работы

Выполнение лабораторной работы предполагает решение следующих задач:

1. Загрузить набор данных SUIM и выполнить предобработку данных, если это необходимо.
2. Реализовать нейронную сеть с использованием фреймворка PyTorch для решения задачи мультиклассовой семантической сегментации.
3. Выбрать подходящую функцию потерь и настроить гиперпараметры обучения.
4. Обучить реализованную нейронную сеть и провести оценку ее эффективности.

## Набор данных SUIM

1. Данные содержат 8 классов. Маска сегментации - трехканальное изображение, каждый канал которого принимает значение 0 или 255: (0, 0, 0), (0, 0, 255) и так далее. На практике в масках встречаются и промежуточные значения, поэтому маску рекомендуется привести к двум уровням: значения меньше 128 установить в 0, значения 128 и больше - в 255.

2. Номер класса закодирован цветом маски: каждый канал принимает значение 0 или 255, и номер получается из этой тройки как двоичное число, где R - старший бит, B - младший.

| Класс | Цвет маски (R, G, B) | Содержание |
| --- | --- | --- |
| 0 | (0, 0, 0) | Фон, вода |
| 1 | (0, 0, 255) | Human divers |
| 2 | (0, 255, 0) | Aquatic plants and sea-grass |
| 3 | (0, 255, 255) | Wrecks and ruins |
| 4 | (255, 0, 0) | Robots and instruments |
| 5 | (255, 0, 255) | Reefs and invertebrates |
| 6 | (255, 255, 0) | Fish and vertebrates |
| 7 | (255, 255, 255) | Sea-floor and rocks |

3. Для упрощения работы рекомендуется объединить в один класс классы 2, 4, 5 и 7: растения, роботов, рифы, дно и камни. После объединения остается 5 классов: 0, 1, 3, 6 и объединенный.

4. Обучение выполняется на данных из папки `train_val`, итоговое тестирование - на папке `TEST`. Использовать данные из `TEST` для обучения или подбора гиперпараметров нельзя.

## Требования к результатам выполнения работы

1. **Структура и содержимое Jupyter Notebook**:

   - Вывести размерности данных: количество примеров в каждой выборке, форму одного изображения и маски.
   - Показать несколько изображений вместе с масками, чтобы подтвердить корректность загрузки.
   - Разработать архитектуру нейронной сети для сегментации с использованием фреймворка PyTorch.
   - После обучения посчитать accuracy, [IoU](https://lightning.ai/docs/torchmetrics/latest/segmentation/mean_iou.html) и визуализировать [confusion matrix](https://scikit-learn.org/dev/modules/generated/sklearn.metrics.confusion_matrix.html) (с нормализацией, `normalize='true'`).
   - Показать результаты сегментации на тестовых изображениях в сравнении с реальными масками.

2. **Выбор архитектуры**:
   - Можно использовать или адаптировать известные архитектуры глубокого обучения.
   - Может быть полезным:
     - уменьшить количество параметров сети и размер входного изображения - это ускоряет сходимость и работу сети, а также снижает риск переобучения.
     - использовать аугментацию данных, а также взвешенные или специализированные функции ошибки. При аугментации преобразования нужно применять к изображению и маске согласованно.
   - Использовать перенос знаний **недопустимо**: предобученные веса брать нельзя, сеть обучается с нуля. Воспроизвести архитектуру известной сети при этом можно.
